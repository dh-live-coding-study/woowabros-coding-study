## Quick start

1. **참여 등록**: 관리자에게 GitHub와 사용할 문제 사이트의 계정을 알리고 GitHub 초대를 수락합니다. [설정 파일](./study.config.json)에서 본인의 참여자 ID와 계정을 확인합니다.
2. **확장 설치**: [ZIP 다운로드](https://github.com/quantum-jumpers/woowabros-coding-study/archive/refs/heads/main.zip) 후 압축을 풉니다. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켜고, **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더 안의 `extension`을 선택합니다.
3. **토큰 발급**: [GitHub 토큰 만들기](https://github.com/settings/personal-access-tokens/new)에서 아래처럼 선택합니다.

   | 항목 | 선택값 |
   | --- | --- |
   | Resource owner | `quantum-jumpers` |
   | Repository access | **Only select repositories** → `woowabros-coding-study` |
   | Repository permissions | **Actions: Read and write**, **Contents: Read-only** |

   승인 대기 상태라면 관리자에게 토큰 승인을 요청합니다.

4. **확장 설정**: 설치한 확장 아이콘을 눌러 아래 값을 입력합니다. 사이트 계정은 사용하는 사이트만 입력합니다.

   | 항목 | 입력값 |
   | --- | --- |
   | GitHub 저장소 | `quantum-jumpers/woowabros-coding-study` |
   | 참여자 ID | 설정 파일의 본인 `id` |
   | 백준 아이디 | 설정 파일의 본인 `baekjoon`, 로그인한 아이디와 같아야 합니다. |
   | 프로그래머스 계정 표시 | 설정 파일의 본인 `programmers` |
   | GitHub 토큰 | 3번에서 발급한 토큰 |

   **제출 수집 켜기**를 선택하고 **저장**한 뒤, 문제 탭을 새로고침합니다.

### 제출하기

- **백준**: 로그인한 상태에서 **내 제출**의 채점 현황을 열어 둡니다. 화면에 보이는 과거 제출도 수집됩니다.
- **프로그래머스**: **제출 후 채점하기**를 누르고 채점이 끝날 때까지 탭을 열어 둡니다.

저장된 풀이는 위 표의 **제출 기록**, 질문과 해설은 **토론**에서 확인합니다. 제출이 누락되면 확장 설정의 **대기 중인 제출 → 다시 확인하고 전송**을 누릅니다.
